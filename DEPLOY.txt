Состав архива:
  - backend/          исходный код серверной части
  - frontend/         исходный код клиентской части
  - docker-compose.yml
  - .env              файл конфигурации (требует заполнения)
  - init.sql          схема и начальные данные базы данных
  - DEPLOY.txt

Требования на сервере:
  - Docker
  - Docker Compose (v2+)

При первом запуске сервер должен иметь доступ в интернет для скачивания базовых образов.

--------------------------------------------------
ШАГ 1. Заполнить файл .env
--------------------------------------------------

Открыть файл .env из архива и заменить значения:

  DB_PASSWORD=придумайте_надёжный_пароль
  JWT_SECRET=длинная_случайная_строка

Пример генерации JWT_SECRET:
  openssl rand -hex 32

--------------------------------------------------
ШАГ 2. Запустить систему
--------------------------------------------------

  docker compose up -d --build

--------------------------------------------------
ШАГ 3. Проверить работу
--------------------------------------------------

Открыть в браузере:

  http://<IP-адрес-сервера>:44444

--------------------------------------------------
РЕЗЕРВНОЕ КОПИРОВАНИЕ
--------------------------------------------------

Рекомендуется настроить автоматическое резервное копирование.
Пример записи в cron (ежедневно в 02:00, хранить 14 копий):

  0 2 * * * cd /путь/к/проекту && docker compose exec -T db pg_dump -U postgres vkr_db > backups/backup_$(date +\%Y-\%m-\%d).sql
  0 3 * * * find /путь/к/проекту/backups -name "*.sql" -mtime +14 -delete

Настройка выполняется командой crontab -e на сервере.
