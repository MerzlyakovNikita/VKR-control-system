# VKR Control System

Веб-система для кафедры, автоматизирующая процессы, связанные с выпускными
квалификационными работами (ВКР) студентов:

- личный кабинет с разделением ролей: руководитель практики, руководитель ВКР, заведующий кафедрой, секретарь кафедры
- закрепление руководителей ВКР за темами студентов
- назначение рецензентов и формирование направлений на рецензию
- импорт графика защит и распределение студентов по датам
- формирование приказов (об утверждении тем, о назначении рецензентов) в формате Word

## Стек

- React, TypeScript
- Node.js, Express
- PostgreSQL
